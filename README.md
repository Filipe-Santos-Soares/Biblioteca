## Visão Geral

Esse projeto simula uma biblioteca com tabelas referentes à autores e livros. Com acesso de apenas o método **GET** para pessoas sem autorização.

>Pessoas autorizadas contém acesso aos métodos POST, GET, DELETE, etc.
